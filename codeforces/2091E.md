# Interesting Ratio

> [Problem on Codeforces](https://codeforces.com/problemset/problem/2091/E)

## Idea

Write $a = g \cdot x$, $b = g \cdot y$ where $g = \gcd(a,b)$ and $\gcd(x,y)=1$. Then $lcm(a,b) = g \cdot x \cdot y$, so $F(a,b) = xy$. For a product of two coprime numbers to be prime, one of them has to be $1$ and the other the prime itself, there's no other way to split a prime factorization between coprime parts. Combined with $a<b$, this pins $x=1$ and $y=p$ for some prime $p$, meaning every valid pair has the shape $a=g$, $b=g \cdot p$.

## Approach

1. Express $a = g x$, $b = g y$ with $g=\gcd(a,b)$, $\gcd(x,y)=1$, giving $F(a,b) = xy$ directly from $lcm(a,b)=gxy$.
2. Since $x$ and $y$ are coprime and $xy$ must be prime, exactly one of them equals $1$; the constraint $a<b$ forces $x=1$, $y=p$ for a prime $p$.
3. This means valid pairs are exactly $(a,b) = (g, gp)$ for a prime $p$ and integer $g \geq 1$ with $gp \leq n$, so the answer for a given $n$ is $\sum_{p \leq n,\ p  prime} \lfloor n/p \rfloor$, since $g$ ranges over $1, \dots, \lfloor n/p \rfloor$.
4. Sieve every prime up to the global bound $10^7$ once and build a prefix-count array `pi[x]` giving the number of primes $\leq x$; this is reused across all test cases, which is why the sum of $n$ over tests is capped rather than $n$ itself.
5. For each query $n$, evaluate $\sum_{p \leq n} \lfloor n/p \rfloor$ with a block sweep over $l$ from $2$ to $n$. Set $r = \lfloor n / \lfloor n/l \rfloor \rfloor$, add $(pi[r]-pi[l-1]) \cdot \lfloor n/l \rfloor$ for that whole block of primes at once, then jump to $l=r+1$. Since $\lfloor n/l \rfloor$ only takes $O(\sqrt{n})$ distinct values, this avoids walking every prime individually.

## Complexity

- **Time:** $O(N \log \log N)$ for the sieve over the global bound $N=10^7$, plus $O(\sqrt{n})$ per test case for the block sweep.
- **Space:** $O(N)$ for the sieve and prime-count prefix array.

## Notes

- Accumulate the per-query sum in a 64-bit integer; $\sum \lfloor n/p \rfloor$ can exceed the range of a 32-bit `int` for $n$ near $10^7$.
- Build the sieve and `pi` array once outside the test-case loop, sized to the largest possible $n$, so repeated queries only pay for the block sweep.
