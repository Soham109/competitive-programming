# Gigantomachy

> [Problem on Codeforces](https://codeforces.com/problemset/problem/2257/B)

## Idea

Count how many boulders each giant can absorb before he gives up. A range is arranged tallest first, so a giant stays on mountain $1$ until it has been chipped just below mountain $2$, then jumps across and the same thing starts over. Mountain $i$ soaks up $h_i - h_{i+1} + 1$ hits, and adding those up cancels every height in the middle, leaving $h_1 + k - 1$ for a range of $k$ mountains. Only the first height and the number of mountains matter, so the rest of the input can be ignored. Bea throws first, so he wins as long as Ver needs no more hits than he does.

## Approach

1. Work out the cost of one mountain. A giant hops forward when the mountain ahead is taller than the one he stands on, and since the range is non-increasing that only happens after his own mountain has been worn down to $h_{i+1} - 1$. Getting there from $h_i$ takes $h_i - h_{i+1} + 1$ hits, and the last mountain has nothing ahead of it, so it takes its full $h_k$ hits down to $0$ before he admits defeat.

2. Add those costs along the range. The sum $(h_1 - h_2 + 1) + (h_2 - h_3 + 1) + \ldots + h_k$ collapses to $h_1 + k - 1$, because each height appears once with a plus and once with a minus. Every mountain after the first costs exactly one hit no matter how tall it is, which is why `ac` and `bc` are built from `a[0]`, `n`, `b[0]` and `m` alone.

3. Compare the two totals with the turn order in mind. Bea throws first, so his $j$-th hit always lands before Ver's $j$-th. If Ver folds after $D_V$ hits and Bea after $D_B$, Bea gets there first exactly when $D_V \leq D_B$, which is the test `bc <= ac`.

4. The remaining heights are still read into `a` and `b` even though nothing uses them, since the input has to be consumed before the next test case begins.

## Complexity

- **Time:** $O(n + m)$ per test case — reading the two ranges is the whole cost, the decision itself being two additions and a comparison.
- **Space:** $O(n + m)$ for the arrays, of which only the first entry of each is ever read.

## Notes

- `ac` and `bc` are $h_1 + k$ rather than the true $h_1 + k - 1$. Both sides are shifted by the same one, so the comparison is unaffected.
- The test is `<=` and not `<` on purpose. Equal totals go to Bea, because throwing first means he lands the deciding hit a half-turn earlier.
- Heights go up to $10^9$ and at most $100$ mountains are added on, so the totals fit an `int` comfortably. `ll` here costs nothing and removes the question.
