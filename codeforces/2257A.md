# Creating Abbreviations

> [Problem on Codeforces](https://codeforces.com/problemset/problem/2257/A)

## Idea

An abbreviation is built out of first letters, and a new abbreviation itself starts with the first letter of whichever word led its sequence. That letter was already available before, so the pool of usable first letters never grows past the letters the $n$ original words start with. That settles the whole problem. An abbreviation can be made exactly when every letter in it is one of those starting letters, and any abbreviation passing that test can be spelled straight out of the original words, so the order the Beaver made them in never matters.

## Approach

1. Take the first letter of each of the $n$ given words, upper-case it, and drop it into `st`. Words are given in lowercase and abbreviations in capitals, so `toupper(s[0])` puts the two alphabets on the same footing before anything is compared.

2. Nothing new ever joins that pool. An abbreviation added to $S$ begins with the first letter of the first word of its sequence, and that letter is already in `st`, so no amount of building unlocks a letter that was missing at the start.

3. That means each abbreviation can be judged on its own against `st`. If every character of `k` is in there, then for each character pick an original word starting with it, line those words up, and the sequence spells `k` in a single operation. No earlier abbreviation is needed, which is why the order they are given in can be ignored.

4. If even one character of one abbreviation is not in `st`, nothing can ever produce it, and the answer is NO. `y` records that and the answer is printed once everything has been read.

## Complexity

- **Time:** $O(L)$ per test case where $L$ is the total length of the strings — one lookup per character in a set that never holds more than $26$ letters.
- **Space:** $O(1)$, since `st` is capped at the $26$ letters of the alphabet.

## Notes

- The scan does not stop at the first bad letter, and it must not. The remaining abbreviations still have to be pulled off the input, or the next test case would start reading them as its own data.
- A word may be reused inside one sequence, so an abbreviation like `AA` needs only a single word starting with A.
