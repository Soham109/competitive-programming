# Jzzhu and Sequences

> [Problem on Codeforces](https://codeforces.com/problemset/problem/450/B)

## Idea

The key insight is that the sequence $f_n$ defined by $f_1 = x$, $f_2 = y$, and $f_n = f_{n-1} - f_{n-2}$ for $n \geq 3$ is periodic with a cycle length of 6. This periodicity arises because the recurrence relation is linear and involves only two terms, so the sequence eventually repeats itself. By reducing $n \pmod{6}$, we can directly determine the value of $f_n$ without computing all the previous terms.

## Approach

1. Recognize that the sequence $f_n$ is defined by $f_1 = x$, $f_2 = y$, and $f_n = f_{n-1} - f_{n-2}$ for $n \geq 3$. Compute the first six terms of the sequence to observe the periodicity:
   $$
   f_1 = x, \quad f_2 = y, \quad f_3 = y - x, \quad f_4 = -x, \quad f_5 = -y, \quad f_6 = -y + x
   $$
   After $f_6$, the sequence repeats.

2. Use the periodicity property to reduce $n \pmod{6}$. This maps $n$ to one of the six cases above:
   - $n \equiv 1 \pmod{6} \implies f_n = f_1 = x$
   - $n \equiv 2 \pmod{6} \implies f_n = f_2 = y$
   - $n \equiv 3 \pmod{6} \implies f_n = f_3 = y - x$
   - $n \equiv 4 \pmod{6} \implies f_n = f_4 = -x$
   - $n \equiv 5 \pmod{6} \implies f_n = f_5 = -y$
   - $n \equiv 0 \pmod{6} \implies f_n = f_6 = -y + x$

3. Compute $f_n$ modulo $10^9 + 7$ to ensure the result fits within the constraints. Use the property that for any integer $a$, $a \pmod{10^9 + 7}$ is in the range $[0, 10^9 + 6]$. If $f_n$ is negative, add $10^9 + 7$ to bring it into this range.

## Complexity

- **Time:** $O(1)$ — The computation only involves a few arithmetic operations and a modulo operation, all of which are $O(1)$.
- **Space:** $O(1)$ — No additional data structures are used.

## Notes

The primary challenge is recognizing the periodicity of the sequence, which allows the problem to be reduced to a constant-time computation. Additionally, handling negative results in modular arithmetic correctly is crucial. Specifically, when $f_n < 0$, adding $10^9 + 7$ ensures the result is non-negative and within the required range.
