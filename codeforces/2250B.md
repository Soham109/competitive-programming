# String Construction

> [Problem on Codeforces](https://codeforces.com/problemset/problem/2250/B)

## Idea

Split $s$ into maximal runs of equal characters (blocks). A block of length $L$ contributes exactly $L-1$ adjacent equal pairs, so summing over all $b$ blocks gives $k = n - b$. Fixing $k$ therefore fixes the number of blocks $b = n - k$, and since blocks alternate between $0$ and $1$, we just need to lay out $b$ alternating blocks whose total lengths hit the balanced counts $\lceil n/2 \rceil$ and $\lfloor n/2 \rfloor$.

## Approach

1. Since $s$ has $b$ maximal blocks whose lengths sum to $n$, the number of adjacent equal pairs is $\sum (L_i - 1) = n - b$, so realizing exactly $k$ pairs requires exactly $h = n - k$ blocks.
2. A single block ($h \leq 1$) forces every character to be equal, which can't satisfy the balance condition for $n \geq 2$, so `solve` reports $-1$ whenever $k > n-2$.
3. Target `n0` $= \lceil n/2 \rceil$ zeros and `n1` $= \lfloor n/2 \rfloor$ ones, since this is the only split with counts differing by at most $1$.
4. Alternate blocks starting with $0$, giving $h0 = \lceil h/2 \rceil$ zero-blocks and $h1 = \lfloor h/2 \rfloor$ one-blocks. Because $h \leq n$, we always have $h0 \leq$ `n0` and $h1 \leq$ `n1`, so the leftover characters `n0 - h0` and `n1 - h1` are nonnegative and can be dumped into any block of the matching parity without changing the block count.
5. Build the first $0$-block with length `n0-h0+1` and the first $1$-block with length `n1-h1+1`, absorbing all the leftover characters while each still counts as a single block. Fill the remaining `h-2` blocks with single alternating characters so the total block count is exactly $h$, which forces exactly $n - h = k$ adjacent equal pairs.

## Complexity

- **Time:** $O(n)$ per test case, dominated by building the output string.
- **Space:** $O(n)$ for the constructed string.

## Notes

Only the first block of each parity gets padded with the leftover characters; where the extra length goes doesn't matter since block count and total character counts are all that determine validity, so concentrating it at the front keeps the construction simple.
