# Bigrams

> [Problem on Codeforces](https://codeforces.com/problemset/problem/2242/A)

## Idea

The key insight is that a repeated bigram arises if and only if at least one letter appears at least three times, or if at least two letters appear at least twice. This is because a repeated bigram requires overlap between adjacent pairs of characters, which can only happen when there are sufficient repetitions of one or more letters to form overlapping pairs.

## Approach

1. For each test case, count the number of letters that appear at least 3 times (`numt`) and the number of letters that appear exactly 2 times (`num2`).
2. If $numt \geq 1$, then it is possible to form a string with repeated bigrams because a single letter appearing at least 3 times can form overlapping bigrams (e.g., "aaa" contains two "aa").
3. If `numt = 0` but $num2 \geq 2$, then it is also possible to form a string with repeated bigrams because two different letters appearing at least twice each can form a repeated bigram (e.g., "abab" contains two "ab").
4. If neither of the above conditions is satisfied, output "NO", as it is impossible to form a string with repeated bigrams.
5. Repeat this process for all test cases.

## Complexity

- **Time:** $O(t \cdot k)$, where $t$ is the number of test cases and $k$ is the number of distinct letters in each test case. This is because we iterate through the $k$ counts for each test case to compute `numt` and `num2`.
- **Space:** $O(k)$ for storing the counts of letters in each test case.

## Notes

- The constraints allow us to focus only on the counts of letters (up to 26 for the Latin alphabet), making the solution efficient even for large inputs.
- The solution avoids constructing the actual string, as the feasibility of forming repeated bigrams depends solely on the counts of letters.
