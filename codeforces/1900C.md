# Anji's Binary Tree

> [Problem on Codeforces](https://codeforces.com/problemset/problem/1900/C)

## Idea

The key observation is that the problem can be reduced to finding the minimum number of letter changes required so that starting from the root, Keksic can always reach a leaf node. For a node to lead to a leaf, its letter must guide Keksic towards one of its children (if they exist) or its parent (if it has no children). This insight allows us to define a dynamic programming state that tracks the minimum cost of ensuring a path to a leaf for each subtree.

## Approach

1. **Define the DP state:** Let `dp[i]` represent the minimum number of changes required to ensure that starting from vertex $i$, Keksic can reach some leaf in the subtree rooted at $i$. For a leaf node, no changes are required, so `dp[i] = 0` if $i$ has no children.

2. **Traverse the tree in reverse post-order:** To compute `dp[i]` for a node $i$, we need the `dp` values of its children. Perform a depth-first search (DFS) to determine the post-order traversal of the tree, and then process nodes in reverse post-order (from leaves to root).

3. **Compute `dp[i]` for internal nodes:** For a non-leaf node $i$, consider:
   - If $i$ has a left child $l$, Keksic can move to $l$ if the letter on $i$ is 'L'. The cost of this move is $0$ if the letter is already 'L', or $1$ otherwise. Add the cost of reaching a leaf from $l$, which is `dp[l]`.
   - Similarly, if $i$ has a right child $r$, Keksic can move to $r$ if the letter on $i$ is 'R'. The cost is $0$ if the letter is already 'R', or $1$ otherwise, plus `dp[r]`.
   - Take the minimum of these costs to compute `dp[i]`.

4. **Output the result:** After processing all nodes, `dp[1]` (the root node) contains the minimum number of changes required for Keksic to reach a leaf.

## Complexity

- **Time:** $O(n)$ per test case. The DFS traversal and the computation of `dp` values both run in linear time relative to the number of nodes.
- **Space:** $O(n)$ per test case for storing the tree structure, `dp` array, and traversal order.

## Notes

- The reverse post-order traversal ensures that all children of a node are processed before the node itself, which is crucial for computing `dp[i]` correctly.
- The problem guarantees that the input describes a valid binary tree, so no additional checks for tree validity are needed.
