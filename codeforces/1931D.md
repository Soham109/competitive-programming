# Divisible Pairs

> [Problem on Codeforces](https://codeforces.com/problemset/problem/1931/D)

## Idea

The key insight is to reformulate the two divisibility conditions into modular arithmetic constraints. For a pair $(i, j)$ to be beautiful, the following must hold:
1. $(a_i + a_j) \bmod x = 0$, which implies $a_i \bmod x = (x - a_j \bmod x) \bmod x$.
2. $(a_i - a_j) \bmod y = 0$, which implies $a_i \bmod y = a_j \bmod y$.

This means that each element $a_i$ can be uniquely identified by its remainders modulo $x$ and $y$. The problem reduces to counting how many previous elements share the same modular constraints to form valid pairs.

## Approach

1. **Reformulate the conditions:** For each element $a_i$, compute:
   - $r_x = a_i \bmod x$, the remainder modulo $x$.
   - $r_y = a_i \bmod y$, the remainder modulo $y$.
   A pair $(i, j)$ is valid if and only if $r_x$ of $a_i$ matches $(x - r_x)$ of $a_j$ and $r_y$ of $a_i$ matches $r_y$ of $a_j$.

2. **Track modular states:** Use a nested map `mp` where `mp[r_x][r_y]` counts how many elements seen so far have remainders $r_x$ and $r_y$. This allows efficient lookup of potential matches for the current $a_i$.

3. **Count valid pairs:** For each $a_i$, calculate the required $r_x = (x - a_i \bmod x) \bmod x$ and $r_y = a_i \bmod y$. Add the count of elements in `mp[r_x][r_y]` to the result, as they form valid pairs with $a_i$. Then, update $mp[a_i \bmod x][a_i \bmod y]$ to include $a_i$.

4. **Repeat for all test cases:** Reset the map `mp` for each test case to ensure independent computations.

## Complexity

- **Time:** $O(n)$ per test case, where $n$ is the size of the array. Each element requires constant-time operations for modular arithmetic and map lookups/updates. Across all test cases, the total complexity is $O(sum of all  n)$, which is bounded by $2 \cdot 10^5$.
- **Space:** $O(n)$ per test case in the worst case, for storing the map `mp`.

## Notes

- The modular arithmetic ensures that all calculations fit within standard integer ranges, avoiding overflow issues.
- The nested map structure efficiently handles the two-dimensional modular constraints without requiring explicit pair storage.
