# Sharky Surfing

> [Problem on Codeforces](https://codeforces.com/problemset/problem/2037/D)

## Idea

The key insight is that Mualani's progress is constrained by the hurdles, which impose minimum jump power requirements to cross them. To minimize the number of power-ups collected, we should prioritize taking the most powerful upgrades available before each hurdle. This greedy approach works because any suboptimal choice (e.g., taking a weaker power-up when a stronger one is available) will result in either the same or a worse outcome, as it may require collecting more power-ups later.

## Approach

1. **Understand hurdle constraints:** Each hurdle $\left[l, r\right]$ requires Mualani to have a jump power of at least $r - l + 2$ to clear it. This is because she must be able to jump from $l$ to $r + 1$ in one go, and the range of her jump is $[x, x + k]$ where $k$ is her current jump power.

2. **Prioritize power-ups:** Since we want to minimize the number of power-ups collected, we should always take the most powerful available power-ups first. This can be efficiently managed using a max-heap (priority queue).

3. **Iterate through hurdles:** For each hurdle $\left[l, r\right]$, check all power-ups located before $l$. Push their values into the max-heap. Then, repeatedly take the most powerful available power-up (pop from the heap) until Mualani's jump power is sufficient to clear the hurdle.

4. **Handle failure cases:** If Mualani's jump power is still insufficient to clear a hurdle after exhausting all available power-ups, output $-1$ for that test case.

5. **Handle the final stretch:** After clearing all hurdles, Mualani must still reach position $L$. Treat this as an additional "hurdle" where the required jump power is $L - r + 1$, where $r$ is the end of the last hurdle (or $1$ if no hurdles exist).

## Complexity

- **Time:** $O(n + m \log m)$ per test case. Iterating through hurdles and power-ups is $O(n + m)$, and each power-up insertion/removal in the priority queue is $O(\log m)$.
- **Space:** $O(m)$ for the priority queue.

## Notes

- The guarantee that hurdles and power-ups are sorted by position allows us to process them in a single pass with two pointers.
- Using a max-heap ensures that the most powerful available power-up is always selected in $O(\log m)$ time.
