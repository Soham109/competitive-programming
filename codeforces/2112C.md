# Coloring Game

> [Problem on Codeforces](https://codeforces.com/problemset/problem/2112/C)

## Idea

The key observation is that Alice wins if and only if the sum of the three red elements she chooses is strictly greater than any single element Bob can color blue. To ensure this, Alice must choose three elements such that their sum is greater than the maximum element in the array. Since Bob can recolor one of the red elements, Alice must also ensure that the sum of the two smallest red elements (after Bob recolors the largest red element) is greater than the maximum element in the array. This insight reduces the problem to finding all valid triplets $(a[i], a[j], a[k])$ (with $i < j < k$) that satisfy both conditions.

## Approach

1. **Sort the array**: Sorting allows us to efficiently evaluate potential triplets using two pointers, as the elements are in non-decreasing order.

2. **Iterate over the largest red element**: For each valid choice of the largest red element $a[k]$, consider all possible pairs $(a[i], a[j])$ with $i < j < k$. The sum of the two smallest red elements in the triplet is $a[i] + a[j]$.

3. **Determine feasibility of the triplet**: For the triplet $(a[i], a[j], a[k])$, Alice wins if:
   - $a[i] + a[j] + a[k] > a[n-1]$ (the sum of all three red elements is greater than the largest element in the array).
   - $a[i] + a[j] > a[k]$ (the sum of the two smallest red elements is greater than the largest red element, ensuring Alice wins even if Bob recolors $a[k]$).

4. **Optimize pair selection with two pointers**: For a fixed $k$, use two pointers to efficiently count all valid pairs $(a[i], a[j])$ such that $a[i] + a[j] > \max(a[k], a[n-1] - a[k])$. This is because $\max(a[k], a[n-1] - a[k])$ is the stricter of the two conditions Alice's triplet must satisfy.

5. **Accumulate valid triplets**: For each $k$, count the valid pairs $(a[i], a[j])$ using the two-pointer technique and add the count to the total.

## Complexity

- **Time:** $O(n^2)$ per test case, as iterating over $k$ and using two pointers for each $k$ both take $O(n)$ time.
- **Space:** $O(n)$ for sorting the array.

## Notes

- Sorting the array simplifies the problem by allowing the use of two pointers to efficiently count valid pairs.
- The condition $\max(a[k], a[n-1] - a[k])$ ensures that all constraints are satisfied simultaneously. This is the core of the optimization.
