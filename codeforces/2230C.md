# Arrange the Numbers in a Circle

> [Problem on Codeforces](https://codeforces.com/problemset/problem/2230/C)

## Idea

The key observation is that for any valid circular arrangement, at least two of the three consecutive cards in every triple must be the same. This implies that the maximum number of cards that can be arranged is determined by the total count of cards, the number of distinct card values, and the availability of duplicate cards to satisfy the condition. Specifically, the solution must maximize the total number of cards while ensuring that there are enough duplicate cards to satisfy the condition for every triple in the circle.

## Approach

1. **Categorize cards by frequency:** Count the number of cards for each distinct value. Let $o$ represent the count of single cards (cards that appear only once), and let $f$ represent the total number of pairs (i.e., $\sum \lfloor c_i / 2 \rfloor$ over all $c_i$). Also, track the total count of all cards as $init = \sum c_i$.

2. **Handle edge cases:** If all cards are single ($o = n$), it is impossible to form a valid circle since no triple of consecutive cards can have at least two equal cards. In this case, the answer is $0$.

3. **Distribute single cards:** Single cards ($o$) can only be used to extend the circle if there are enough duplicates to pair them with. The number of single cards that can be used is limited by the number of extra duplicates available. Define $extra = \sum (c_i - 2) / 2$ for all $c_i \geq 2$. If there is only one distinct card type with duplicates, the maximum number of single cards that can be paired is $\min(o, f)$; otherwise, it is $\min(o, extra)$.

4. **Calculate the result:** The maximum number of cards that can be arranged in a circle is $init + \min(o, extra)$ (or $init + \min(o, f)$ in the special case of only one distinct card type). If this result is less than $3$, output $0$ since at least three cards are needed to form a valid circle.

5. **Repeat for all test cases:** Perform the above steps for each test case and output the result.

## Complexity

- **Time:** $O(n)$ per test case, where $n$ is the number of card types. Summing over all test cases, the total complexity is $O(sum of all  n \leq 2 \cdot 10^5)$.
- **Space:** $O(n)$ per test case for storing card counts.

## Notes

- Handling the special case where all cards are single is crucial, as no valid circle can be formed in that scenario.
- The calculation of $extra$ ensures that the solution considers only the surplus duplicate cards after accounting for the minimum required to form pairs. This is essential for maximizing the circle size.
