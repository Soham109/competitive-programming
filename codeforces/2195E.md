# Idiot First Search

> [Problem on Codeforces](https://codeforces.com/problemset/problem/2195/E)

## Idea

Whenever Bob steps onto a blank vertex $v$, he explores its whole subtree and comes back to $v$ before leaving, and every vertex below $v$ is blank again by then, because each vertex cycles through nothing, `L`, `R`, nothing. So the time spent inside a subtree depends only on the subtree itself. And since Bob starts below his parent without ever having visited it, the parent is still blank when he first climbs to it, which lets the answers chain along the path to the root.

## Approach

1. Define `dp[x]` as the time from Bob stepping onto a blank $x$ until he is back on $x$ with `R` written and everything below blank. A leaf has nothing to explore, so `dp[x] = 0`. For an internal vertex, Bob goes left (1 move), finishes the left subtree (`dp[l[x]]`), returns (1 move), goes right (1 move), finishes the right subtree (`dp[r[x]]`) and returns (1 move), so `dp[x] = 4 + dp[l[x]] + dp[r[x]]`.

2. Starting at $k$, Bob spends `dp[k]` exploring, then erases the letter and climbs to the parent, which is `+ 1`. The parent $p$ has never been visited, so it is blank, and every vertex in its subtree is blank too. From here Bob behaves exactly as if he had started at $p$, so the rest costs `ans[p]`. That gives `ans[x] = dp[x] + 1 + ans[parent[x]]`.

3. The root's parent is left at its default `parent[1] = 0`, and `ans[0] = 0`, so climbing out of the root adds just the final move and the chain stops there.

4. The recurrence for `dp` needs children before parents, while `ans` needs parents before children. A breadth first order stored in `order`, built from vertex $1$ by pushing `l[x]` and `r[x]`, gives both for free. Scanning `order` backwards fills `dp` bottom up, and scanning it forwards fills `ans` top down, so every value is computed once from values that are already final. Each sum is taken $\pmod{10^9+7}$ because the true times grow exponentially with depth.

## Complexity

- **Time:** $O(n)$ per test, since building `order`, filling `dp` and filling `ans` each visit every vertex once.
- **Space:** $O(n)$ for `l`, `r`, `parent`, `dp`, `ans` and `order`.

## Notes

- Vertex $0$ is only a sentinel with `ans[0] = 0`, and `parent[1] = 0` is left at its default, so no special case is needed for the root's child.
- `dp` and `ans` use `long long`, and each addition reduces modulo $10^9+7$ immediately, so sums of at most three residues never overflow.
