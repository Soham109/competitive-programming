# Big Vova

> [Problem on Codeforces](https://codeforces.com/problemset/problem/1407/B)

## Idea

Lexicographic order is decided at the first position where two sequences differ, so a larger $c_i$ early outweighs anything that happens later. The prefix gcd only ever holds steady or shrinks, and each $c_i$ divides $c_{i-1}$, so a value given up early can never be recovered. Taking the largest $c_i$ available at every step is therefore safe.

## Approach

1. Sort `a` in decreasing order and place `a[0]` first, because $c_1 = b_1$ means the opening value is maximized by the largest element outright. Seed the running prefix gcd with `g = a[0]`, since only that first element depends on the sort.
2. For each remaining position, scan every index still unmarked in `used` and keep `idx`, whose gcd with `g` is the largest, tracking that gcd in `mx`. Starting `mx` at $0$ is safe because every $a_j \geq 1$ yields a gcd of at least $1$, so some candidate always wins.
3. That maximum is exactly the best $c_i$ reachable given the earlier picks, because $c_i = \gcd(c_{i-1}, b_i)$ depends only on `g` and the number placed next. Ties need no tiebreak: if $x$ and $y$ both give $g'$, taking $x$ leaves $y$ available with $\gcd(g', y) = g'$, already the most $c_{i+1}$ can be.
4. Fold the winner into `g`, mark it in `used`, and store it in `ans[i]`, which carries the prefix gcd forward. Once `g` reaches $1$ every remaining candidate ties at $1$ and the same scan fills the rest in arbitrarily.

## Complexity

- **Time:** $O(n^2 \log A)$ with $A \leq 10^3$, from $n$ scans of up to $n$ candidates, each doing a gcd.
- **Space:** $O(n)$ for `a`, `ans`, and the `used` flags.
