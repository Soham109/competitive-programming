# Big Vova

> [Problem on Codeforces](https://codeforces.com/problemset/problem/1407/B)

## Idea

Lexicographic order is decided at the first position where two sequences differ, so a larger $c_i$ early outweighs anything that happens later. The prefix gcd only ever holds steady or shrinks, and each $c_i$ divides $c_{i-1}$, so a value given up early can never be recovered. Taking the largest $c_i$ available at every step is therefore safe.

## Approach

1. Keep the running prefix gcd in `g` and start it at $0$, because $\gcd(0, x) = x$ makes the first pick come out as the maximum element with no special case.
2. At each of the $n$ steps, scan every index not yet marked in `used` and keep the one whose gcd with `g` is largest, since that gcd is exactly the $c_i$ that choice would produce.
3. Ties need no tiebreak, because if $x$ and $y$ both give $g'$, then taking $x$ leaves $y$ available with $\gcd(g', y) = g'$, which is already the most $c_{i+1}$ can be, so the strict `>` that keeps the first maximum suffices.
4. Mark the winner in `used`, fold it into `g`, and print it, which carries the prefix gcd forward. Once `g` reaches $1$ every remaining candidate ties at $1$, and the same scan fills the rest in arbitrarily.

## Complexity

- **Time:** $O(n^2 \log A)$ with $A \leq 10^3$, from $n$ scans of up to $n$ candidates, each doing a gcd.
- **Space:** $O(n)$ for `a` and the `used` flags.
