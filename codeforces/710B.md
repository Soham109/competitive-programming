# Optimal Point on a Line

> [Problem on Codeforces](https://codeforces.com/problemset/problem/710/B)

## Idea
The key insight is that the optimal point $x$ minimizing the sum of absolute distances to $n$ points is the **median** of the given coordinates. This follows from a well-known property of the median: it minimizes the sum of absolute deviations in a one-dimensional space. If there are multiple medians (when $n$ is even), the leftmost median is chosen because it results in the same minimum sum but satisfies the problem's requirement to output the smallest possible $x$.

## Approach
1. Sort the array of coordinates in non-decreasing order. Sorting ensures that the median can be easily located, as it divides the data into two halves of equal size (or nearly equal size if $n$ is odd).
2. Identify the median:
   - If $n$ is odd, the median is the middle element of the sorted array, located at index $\lfloor n / 2 \rfloor$.
   - If $n$ is even, there are two middle elements in the sorted array. The leftmost median is chosen, which corresponds to the element at index $(n - 1) / 2$.
3. Output the value of the median. This guarantees the minimal sum of absolute distances to all points.

## Complexity
- **Time:** $O(n \log n)$ — dominated by the sorting step.
- **Space:** $O(1)$ — sorting is done in-place, and no additional space is used apart from the input array.

## Notes
The problem guarantees that the optimal point is always an integer, so no further rounding or approximation is needed.
