# BerSU Ball

> [Problem on Codeforces](https://codeforces.com/problemset/problem/489/B)

## Idea

The key observation is that pairing a boy and a girl with the smallest absolute difference in dancing skills minimizes conflicts and maximizes the number of valid pairs. Sorting both skill arrays ensures that the smallest differences are checked first, allowing a greedy approach to work optimally. This is because once a valid pair is formed, neither participant can be used again, so it is always optimal to pair the closest match available.

## Approach

1. Sort the arrays `a` and `b` of boys' and girls' dancing skills in non-decreasing order. Sorting ensures that the smallest differences are considered first, which is crucial for the greedy pairing strategy.
2. Use two pointers `j` and `k` to traverse the sorted arrays. Start both pointers at the beginning of their respective arrays.
3. At each step, compare the values at `a[j]` and `b[k]`. If their absolute difference is $\leq 1$, form a pair, increment both pointers, and increase the pair count `tot` because this guarantees a valid pairing.
4. If $a[j] < b[k]$, increment `j` to check the next boy since the current boy cannot pair with the current girl.
5. If $a[j] > b[k]$, increment `k` to check the next girl since the current girl cannot pair with the current boy.
6. Repeat steps 3-5 until one of the pointers reaches the end of its array. At this point, no further pairs can be formed, and the value of `tot` is the maximum number of pairs.

## Complexity

- **Time:** $O(n \log n + m \log m)$ — dominated by sorting the arrays `a` and `b`.
- **Space:** $O(1)$ — only constant space is used for pointers and counters.

## Notes

- Sorting both arrays is essential to ensure the greedy approach works correctly, as it allows us to consider pairs in increasing order of skill difference.
- The use of two pointers avoids the need for nested loops, making the solution efficient even for the upper bound of $n, m = 100$.
