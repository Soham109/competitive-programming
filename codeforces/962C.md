# Make a Square

> [Problem on Codeforces](https://codeforces.com/problemset/problem/962/C)

## Idea

The key insight is that any square number can be represented as a contiguous sequence of digits from the original number $n$, as long as leading zeros are avoided. This allows us to reformulate the problem as finding the smallest number of deletions needed to extract a subsequence of $n$ that forms a perfect square. To verify if a number is a perfect square, we can compute its square root and check if squaring it reproduces the original number.

## Approach

1. **Enumerate subsequences**: Represent the number $n$ as a string `sn` to facilitate subsequence extraction. Use bitmasking to generate all possible subsequences of `sn`. Each bitmask represents whether a digit is included in the subsequence.

2. **Filter invalid subsequences**: Discard subsequences that are empty or start with a leading zero, as they cannot form valid integers.

3. **Check for perfect squares**: For each valid subsequence, convert it to an integer and check if it is a perfect square using the `isSquare` function. This function computes the square root of the number and checks if squaring the result equals the original number.

4. **Track the minimum deletions**: For each valid subsequence that is a perfect square, calculate the number of deletions required to form it from the original number. This is given by the difference between the length of `sn` and the length of the subsequence. Keep track of the minimum deletions across all valid subsequences.

5. **Output the result**: If no valid subsequence forms a perfect square, output $-1$. Otherwise, output the minimum number of deletions found.

## Complexity

- **Time:** $O(2^m \cdot m)$, where $m$ is the number of digits in $n$. This comes from generating all $2^m$ subsequences and performing $O(m)$ operations (subsequence creation, validation, and perfect square check) for each one.
- **Space:** $O(m)$ for storing the string representation of $n$ and temporary subsequences.

## Notes

- The `isSquare` function uses `sqrt` and checks for equality to determine if a number is a perfect square. This avoids overflow issues, as we only handle integers within the range of $[1, 2 \cdot 10^9]$.
- The use of bitmasking ensures that all subsequences are generated systematically, and the constraints of the problem (no leading zeros, valid integers) are enforced during filtering.
