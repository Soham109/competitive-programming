# Evanescent

> [Problem on Codeforces](https://codeforces.com/problemset/problem/2254/B)

## Idea

$|f(s)|$ only depends on how many adjacent pairs differ, since every maximal block collapses to one character. Deleting $s_i$ can only ever touch the two transitions that touch position $i$, namely $(s_{i-1}, s_i)$ and $(s_i, s_{i+1})$; everything else in the string keeps its original block boundaries. So the whole problem reduces to a local case check at each candidate index instead of recomputing the compression from scratch.

## Approach

1. Compute the base compressed length $r$ of $s$ as $1$ plus the number of indices $i$ with $s_i \neq s_{i-1}$, since that count is exactly the number of block boundaries.
2. For a candidate deletion at index $i$ ($1 \leq i \leq n-2$ in 0-indexed terms), note that removing $s_i$ glues $s_{i-1}$ and $s_{i+1}$ together, so only the two transitions around $i$ can change and every other boundary in the string survives untouched.
3. If $s_{i-1} = s_{i+1}$ and $s_i \neq s_{i-1}$, then $s_i$ was a lone character wedged between two equal blocks; deleting it merges those blocks and erases both surrounding transitions, dropping the length by $2$.
4. If $s_i$ differs from both neighbors but $s_{i-1} \neq s_{i+1}$, the two transitions around $i$ collapse into a single new transition between $s_{i-1}$ and $s_{i+1}$, so the length only drops by $1$.
5. Otherwise $s_i$ equals at least one neighbor, meaning it already sat inside an existing block; deleting it shrinks that block without touching any transition, so the length stays at $r$.
6. Evaluate this cost for every valid $i$ and take the minimum, since deletions are independent local perturbations of the same base value $r$.

## Complexity

- **Time:** $O(n)$, one pass to build $r$ and one pass to evaluate every candidate index.
- **Space:** $O(1)$ beyond the input string.
