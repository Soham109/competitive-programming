# Threshold Movement

> [Problem on Codeforces](https://codeforces.com/problemset/problem/2250/A)

## Idea

The core insight is that the array must alternate between "heavy" and "light" elements such that every "heavy" element is strictly greater than its neighboring "light" element. This ensures the ball can move left or right depending on the threshold comparison. If this alternation is violated at any position, the answer is "NO". Additionally, the global minimum of the "heavy" elements must be strictly greater than the global maximum of the "light" elements to allow a valid threshold range.

## Approach

1. Verify that the array length $n$ is even. If $n$ is odd, it is impossible to pair elements into "heavy" and "light" groups, so output "NO".
2. Iterate through the array in pairs: for every even index $i$, compare $a[i]$ (the "heavy" element) and $a[i+1]$ (the "light" element). If $a[i] \leq a[i+1]$, the alternation rule is violated, so output "NO".
3. Track the minimum value among all "heavy" elements (`l`) and the maximum value among all "light" elements (`r`) as you iterate. These values represent the boundaries of the threshold range.
4. After processing all pairs, check if $l - r > 1$. This ensures there exists a valid threshold that separates "heavy" and "light" elements. If not, output "NO".
5. If all conditions are satisfied, output "YES".

## Complexity

- **Time:** $O(n)$ — a single pass through the array to validate the conditions and compute the thresholds.
- **Space:** $O(1)$ — only a few variables are used for tracking thresholds.

## Notes

- The condition $l - r > 1$ guarantees that there is at least one integer threshold separating the "heavy" and "light" groups. This is critical for the solution's correctness.
